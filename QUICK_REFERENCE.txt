================================================================================
                    THEME SYSTEM - QUICK REFERENCE CARD
================================================================================

🎨 WHAT IT DOES
  • Switch between dark and light themes
  • Logo changes automatically with theme
  • User preference saves and persists
  • Smooth animations and transitions
  • Full accessibility support

================================================================================
                           HOW TO USE IT
================================================================================

USER LEVEL:
  1. Click the moon/sun toggle button in top-right header
  2. Theme changes instantly
  3. Logo updates to match theme
  4. Done! (Preference saved automatically)

DEVELOPER LEVEL (in browser console):
  window.toggleTheme()              → Toggle theme
  window.setTheme('light-theme')    → Set to light
  window.setTheme('dark-theme')     → Set to dark
  window.getTheme()                 → Get current theme
  ThemeDebug.healthCheck()          → Verify system working
  ThemeDebug.info()                 → Show all commands

================================================================================
                        GLOBAL FUNCTIONS
================================================================================

THEME CONTROL:
  window.toggleTheme()              Toggle between themes
  window.setTheme(theme)            Set specific theme
  window.getTheme()                 Get current theme
  
ACCESS MANAGER:
  window.themeManager               ThemeManager instance
  window.ThemeDebug                 Debug utilities

LISTEN FOR CHANGES:
  window.addEventListener('themeChanged', (e) => {
    console.log('Theme:', e.detail.theme);
  });

================================================================================
                       DEBUG CONSOLE COMMANDS
================================================================================

VERIFICATION:
  ThemeDebug.healthCheck()          Full system check
  ThemeDebug.getState()             Get current state
  ThemeDebug.info()                 Show help menu

TESTING:
  ThemeDebug.testSwitch()           Test theme toggle
  ThemeDebug.testLogo()             Check logo elements
  ThemeDebug.updateLogo()           Force logo update

CONTROL:
  ThemeDebug.setTheme('light-theme')  Set light theme
  ThemeDebug.setTheme('dark-theme')   Set dark theme
  ThemeDebug.reset()                Reset to default

================================================================================
                      TROUBLESHOOTING
================================================================================

ISSUE: Toggle button not working
  → Run: ThemeDebug.healthCheck()
  → Check for errors in console
  → Try: window.themeManager.reinitialize()

ISSUE: Logo not changing
  → Run: ThemeDebug.testLogo()
  → Check: images/YomlinksLogo.jpg exists
  → Check: images/YomlinksLogoLight.jpg exists
  → Try: ThemeDebug.updateLogo()

ISSUE: Theme doesn't persist
  → Run: ThemeDebug.getState()
  → Check localStorage: localStorage.getItem('yomlinks-theme')
  → Try: ThemeDebug.reset()

ISSUE: Styling looks wrong
  → Clear cache: Ctrl+Shift+Delete
  → Hard refresh: Ctrl+F5
  → Check CSS variables defined
