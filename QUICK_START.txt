HOW TO CUSTOMIZE
=============================================================================

COLORS:
Edit style.css :root variables:

  --accent-color: #00d9ff
  --text-primary: #ffffff
  (and other color variables)

CONTENT:
Edit HTML files directly:
- Product names, descriptions, prices
- Team member names and roles
- Service descriptions
- Contact information

IMAGES:
Replace image paths in HTML with your own images

FONTS:
Change font imports in HTML head or CSS
